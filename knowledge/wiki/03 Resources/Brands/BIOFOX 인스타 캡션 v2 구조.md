# BIOFOX 인스타 캡션 v2 구조

## 개요
기존 n8n 캡션 구조(v1)의 문제점을 분석하고 전면 리뉴얼한 캡션 구조.
목표: DM/댓글 전환율 극대화 + 인스타 알고리즘 최적화.

## v1의 문제점
- 후킹 테이블 24종이 전부 "~~ 천방케어" 패턴 → 3개만 올라가면 같은 글
- 300-400자 감성 에세이 → "고객 울면서 옴→천방케어→주변 알아봄→원장 감동" 반복
- CTA 4줄이 저장+댓글+공유 동시 요구 → 선택지 많으면 아무것도 안 함
- 천방케어 3회+바이오폭스 1회 강제 → 억지 삽입으로 광고 냄새
- 비포/애프터 위치 확정 표현 → 실제 배치와 다를 수 있음

## v2 캡션 구조

```
날것 첫 줄 (원장의 날것 한마디)

message 활용 중간 (고객 상황/맥락 1-2줄)
검색 키워드 자연 삽입 1줄

궁금하면
"천방케어" 남겨주세요.
나중에 또 보려면 저장해두세요 📌

#천방케어 #마이크로젯 #바이오폭스
#카테고리 해시태그 #지역 #샵명

------
각주 3줄
```

### 파트별 상세

#### 1. 날것 첫 줄
원장이 실제로 꺼낼 법한 말. 카피가 아니라 반응.

톤 가이드:
- "아 이건 올려야 돼요"
- "고객님 허락받고 올립니다"
- "3회차인데요"
- "오늘 관리하다가 소름"
- "아까 끝나고 고객님이 안 가세요"
- "이분 첫 방문 때 영상이 있는데"

원칙:
- 멋진 말 없음
- 상황 한 줄만 던짐
- 정리 안 된 느낌
- "더보기" 누르게 하는 건 카피가 아니라 "진짜 겪은 거 같아서"

#### 2. message 활용 중간
원장이 입력한 고객 에피소드(message 필드)에서 가장 강한 한 문장을 뽑아 활용.
고객의 실제 말을 인용하거나, 상황 맥락을 1-2줄로.

규칙:
- 에피소드를 요약하지 말고 한 장면만
- 고객 직접 인용이 가장 강력
- 변화 서사 금지 (파운데이션 바꿨다, 거울 안 본다 등 AI 클리셰)
- 확정 수치/날짜/회차/비포애프터 위치 금지

검색 키워드 삽입:
- 지역명 + "피부관리" 또는 "에스테틱" 자연스럽게 1회
- 원장 경력이나 리액션으로 신뢰 한 줄 추가
- 예: "수원 피부관리 10년차인데 이런 변화는 저도 놀랐어요"

#### 3. CTA
```
궁금하면
"천방케어" 남겨주세요.
나중에 또 보려면 저장해두세요 📌
```

원칙:
- 행동은 하나: "천방케어" 댓글
- "받아보고 싶으면" 금지 — 벽이 높음. "궁금하면"이 문턱 낮음
- 저장 유도 1줄 추가 (알고리즘 부스트)
- DM 안내는 선택: "DM 드릴게요" 추가 가능

#### 4. 해시태그
- 3-8개 (과거 20-30개 스타일 금지)
- 필수: #천방케어 #마이크로젯 #바이오폭스
- 지역: #[지역]에스테틱 #[지역]피부관리 #[샵명]
- 카테고리별 2-3개 추가
- 해시태그를 댓글로 옮기는 것도 가능 (트렌드)

#### 5. 각주
```
※ 천방케어는 MICROJET 기기를 이용하여 BIOFOX의 10-GF 성분을 흡수시키는 에스테틱 관리 프로그램의 명칭입니다.
※ 주름개선/미백 효과는 주름개선/미백 이중기능성을 획득한 BIOFOX 제품에 한한 내용입니다.
※ MICROJET 미용기기는 BIOFOX 제품의 흡수를 도와주는 목적으로만 사용됩니다.
```

## 브랜딩 규칙 (v2)

| 항목 | v1 | v2 |
|------|----|----|
| 천방케어 노출 | 3회 이상 강제 | 본문 1회 + CTA 1회 + 해시태그. 억지 반복 금지 |
| 바이오폭스 노출 | 본문 1회 필수 | 해시태그에서만. 본문 강제 삭제 |
| 후킹 | 테이블 24종 | 폐지. 날것 첫 마디 톤 가이드 |
| 캡션 길이 | 300-400자 | 제한 없음. 짧을수록 좋음 |
| CTA | 4줄 (저장+댓글+공유+네이버) | "천방케어" 댓글 1줄 + 저장 1줄 |
| 비포애프터 위치 | 확정 가능 | 위치·순서 특정 금지 |
| 날짜/회차/수치 | 확정 가능 | 확정 금지 (실제와 다를 수 있음) |

## 컴플라이언스 (v1과 동일, 변경 없음)

### 호칭
모든 호칭 → "고객님" (예외: 예비신부 → "예비신부 고객님")

### 금지 → 우회

| 금지 | 대체 |
|------|------|
| 역노화/리버스에이징 | 젊어지는 피부 / 시간을 되돌리는 |
| 홍조 | 붉고 예민해지는 피부 |
| 기미 | 칙칙한 피부 |
| 여드름 | 갑자기 올라오는 울긋불긋함 |
| 아토피 | 예민하고 가려운 피부 |
| 리프팅 | 탄력 있는 피부 |
| 모공 축소 | 매끈해지는 피부결 |
| 미백 | 맑고 환한 피부톤 |
| 재생/피부재생 | 피부에 활력을 더하는 / 피부 자생 |
| 치료/시술/주사 | 케어/관리/천방케어 |
| 침투 | 흡수/도포/전달 |
| 트러블 | 울긋불긋한/올라오는/예민한 피부 |
| 셀프케어 | 천방케어/전문 관리 |
| 병원/피부과/의원 | 언급·비교 자체 금지 |

### 절대 금지
- 질환명 직접 언급
- 의료 행위 암시 (해결/치료/개선/탈출/제거)
- 병원·피부과·의원 언급·비교
- 시술 암시 (~해드려요/펴드려요)
- 과장 (완벽/기적/100%)

### 해시태그 금지
#홍조탈출 #기미제거 #여드름치료 #아토피케어 #셀프케어 #피부과 #리프팅 #의원 #병원

## 2025-2026 인스타 트렌드 반영 근거

### 반영된 트렌드
- "Comment [keyword] → DM" 패턴이 2025 글로벌 최대 트렌드 → "천방케어" 댓글 구조
- 저장 CTA가 알고리즘 최우선 신호 → 저장 유도 추가
- 인스타 캡션 텍스트 검색 인덱싱 시작 → 검색 키워드 삽입
- 릴스 캡션은 짧은 게 최적 (1-5줄) → 길이 제한 폐지, 짧을수록 좋음
- 해시태그 3-8개가 최적 (과거 20-30개 X) → 해시태그 축소
- "전문가 친구" 톤이 최고 전환율 → 날것 구어체
