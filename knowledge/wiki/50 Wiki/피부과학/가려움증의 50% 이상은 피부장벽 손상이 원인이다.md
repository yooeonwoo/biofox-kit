# 가려움증의 50% 이상은 피부장벽 손상이 원인이다

## Main Idea
피부과 환자의 절반 이상이 가려움증으로 내원하며, 가장 흔한 원인은 피부장벽 기능 저하로 인한 건조성 가려움증이다. 피부장벽이 손상되면 피부가 건조해지고, 이것이 가려움을 유발하는 주된 메커니즘이다.

## Context
단순히 '건조하니까 가렵다'가 아니라, 피부장벽 기능 저하라는 구체적 메커니즘을 이해해야 근본적 해결이 가능하다.
