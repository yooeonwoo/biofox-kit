# BIOFOX 유튜브 퍼널 설계

## 채널 구조

### 본사 운영 (3개)
1. **브랜드 오피셜 채널** — 브랜딩 + 신뢰 + 고객 스토리 중심
   - 실제 천방케어 관리 과정 (ASMR/시술 영상)
   - 비포애프터 (릴스 재편집)
   - 원장 인터뷰/멘트
   - 메디프레스/프리클린 사용법
   - 빈도: 주 1-2회
   - 퍼널 필수 경유지 아님. "천방케어 뭐지?" 검색 시 신뢰 확인용

2. **서브채널 1** — AI 자동화 정보전달형 (먼저 런칭)
   - 피부재생 과학, 40대+ 관리법 등
   - 7분 롱폼 + 숏폼 파생

3. **서브채널 2** — 추후 추가 (다른 스타일)

### 외부 채널
- **에이징유**: 별도 운영팀. 주1 미드폼(5분) + 숏폼3개. 본사 관여X
- **송선미**: 개인 채널에 BIOFOX 간접 노출만. 제품 전면 노출 금지, 궁금증 유발만. 셀프 가이드라인 제공

## 타겟

| 타겟 | 핵심 질문 | 특성 |
|------|----------|------|
| A. 40대+ 여성 | "왜 확 늙지?", "왜 재생 안 되지?", "왜 처지지?" | 노화 고민 |
| B. 시술 후처치 검색자 | "시술 후 선크림 뭐 바르지?" | 나이 무관 |

## 주제 시스템 (8개 슬롯)

### 타겟 A: 노화/재생 (40대+ 여성)
- **A1 원인형**: 왜 무너지는가 — "40대부터 확 처지는 이유", "콜라겐 줄어드는 진짜 이유"
- **A2 오해형**: 잘못 알고 있는 것 — "콜라겐 영양제 먹으면 피부에 가나", "고가 크림이면 재생되나"
- **A3 비교형**: 이것 vs 저것 — "보톡스 vs 레이저", "리프팅 vs 재생"
- **A4 방법형**: 어떻게 하면 되는가 — "처진 피부 관리 순서", "재생력 올리는 조건"

### 타겟 B: 시술 후처치 (나이 무관)
- **B1 직후형**: 시술 직후 뭐 해야 하나 — "레이저 후 첫 24시간", "시술 당일 세안"
- **B2 제품형**: 뭐 발라야 하나 — "시술 후 선크림 고르는 기준", "절대 안 되는 성분"
- **B3 실수형**: 이거 하면 망한다 — "시술 후 사우나", "각질 뜯기", "효과 반토막 습관"
- **B4 루틴형**: 며칠간 뭐 하면 되나 — "시술 후 3일 루틴", "1주일 타임라인"

## 퍼널 흐름

```
서브채널 (7분 롱폼 정보전달)
  │
  ├─ 고정댓글: 카카오 채널 링크
  ├─ Verbal CTA: "카카오에서 답변드려요" or "검색창에 OOO"
  ├─ 댓글 유도 → 답변에서 카카오 안내
  ├─ 숏폼 클립 → 롱폼 유입 순환
  │
  └──→ 카카오 채널
        ├─ 자동 환영 메시지 (분기별 응답)
        │   [시술 후 관리] [피부 노화] [제품 추천]
        ├─ 1:1 상담 전환
        ├─ 메디프레스/프리클린 스마트스토어
        └─ 천방케어 상담 연결

오피셜 채널 = 독립적 브랜드 신뢰 보강
```

### 전환 장치 (리드마그넷 대신)
1. **고정댓글** — 설명란보다 5-10배 노출. 카카오 채널 링크
2. **Verbal CTA** — "검색창에 OOO 치세요" (브랜드 검색량 ↑)
3. **숏폼→롱폼 파이프라인** — 숏폼으로 발견, 롱폼으로 신뢰
4. **커뮤니티 탭** — 투표/질문으로 관계 형성
5. **댓글 유도** → 답변에서 카카오 안내

### 왜 리드마그넷이 안 먹히는가
- 유튜브 설명란 클릭 자체가 행동 비용 높음
- 한국 시장에서 이메일 수집 문화 없음
- **"교육 영상 자체가 프리셀링"** (Dr. Eric Berg 모델)

## OSMU (One Source Multi Use)

유튜브 대본 = 원천소스

| 원천 | 파생 콘텐츠 |
|------|-----------|
| 7분 롱폼 대본 | PPT 영상 or 애니 영상 |
| ↓ | 숏폼 클립 60초 × 2-3개 |
| ↓ | 인스타 릴스 15초 |
| ↓ | 인스타 캡션 |
| ↓ | 네이버 블로그 (심화) |
| ↓ | 카드뉴스 |
| ↓ | 틱톡 (보조, 있는 콘텐츠 활용) |

- 1주제 = 최대 12개 콘텐츠
- 월 8주제 = 약 100개 콘텐츠
- AI 자동화로 다채널 운영, 사람은 품질체크 + 원천소스에 집중

## 콘텐츠 변주 설계 (대표님 GPT 대화)

### 핵심 인사이트
- "같은 메시지를 다양한 시각에서 전달하는 것"
- AI 혼자 기획하면 단조로워지는 한계 있음

### 해결 구조
- **진입 주제**: 레퍼런스 채널에서 가져와 구조화
- **결론 스타일/뉘앙스**: 몇 가지로 정해서 매칭
- **포맷**: 정해진 구조 안에서 변주
- **정량 설계(AI) + 정성 설계(대표님) 분업**

### 미완성 과제
- 채널 1개 기준: 진입 수 / 구조 수 / 결론 스타일 수 역설계
- 1년 운영 설계

## 브랜드 채널 콘텐츠 방향

- 시술 중심보다 **고객 스토리 중심** (광고법/의료법 우회)
- 에스테틱 원장님 사용자 관점 설명 (리쥬란 레퍼런스)
- 우리 정보 노출, 케어 효과 정보
- 제품을 전면에 내세우면 신뢰/호기심 떨어짐 → 간접 노출
