# 피부는 스마트한 자가교정 시스템을 가지고 있다

## Main Idea
유분 부족이든 수분 부족이든 결국 보습제로 해결된다. 우리 몸은 바보가 아니어서 부족한 부분을 자동으로 보상해준다. 수분 공급만 제대로 하면 피부가 알아서 밸런스를 맞춘다.

## Context
복잡한 케어보다 기본적인 보습이 피부 문제 해결의 핵심이다.
