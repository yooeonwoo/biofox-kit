# BIOFOX 비포애프터 릴스 대본 템플릿

## 구조 개요
천방케어 시술 흐름을 그대로 대본 구조로 쓴다.
영상은 실제 시술 과정을 보여주면서 자막으로 대본이 나간다.

```
비포 (후킹)
  ↓
레이저 (천방케어 키워드)
  ↓
에어젯 (재생인자 키워드)
  ↓
초음파 (재생인자 키워드)
  ↓
애프터 (후킹 + CTA 댓글유도)
```

## 각 파트 역할과 규칙

### 1. 비포 (후킹)
- 역할: 시술 전 피부 상태를 보여주면서 스크롤을 멈추게 한다
- 규칙:
  - 1문장, 최대 2문장
  - 짧고 직감적
  - 설명 금지, 반응이 먼저
  - 고객이 "어? 내 얘기인데" 또는 "와, 뭐야 저거" 느끼게
- 톤 예시:
  - "이 피부가 이렇게 달라져요."
  - "이번엔 진짜 달랐어요."
  - "와, 이건 받고 싶다."
  - "이 피부 상태에서 시작했어요."

### 2. 레이저 (천방케어)
- 역할: 어븀야그 프락셔널 레이저 단계를 보여주면서 천방케어를 자연스럽게 언급
- 규칙:
  - 1~2문장
  - "천방케어" 키워드 반드시 포함
  - 레이저가 뭘 하는지 고객 언어로 짧게
  - 학술 설명 금지 → 체감 표현으로
- 톤 예시:
  - "천방케어 레이저로 피부 길을 열어줘요."
  - "천방케어 첫 단계, 레이저로 피부에 통로를 만들어요."
  - "레이저로 피부가 받아들일 준비를 해요."

### 3. 에어젯 (재생인자)
- 역할: 에어젯으로 10GF/성장인자를 전달하는 장면. 재생인자 키워드 삽입
- 규칙:
  - 1~2문장
  - "재생인자" 또는 "성장인자" 또는 "10GF" 중 하나 포함
  - 뭘 넣는지보다 넣으면 뭐가 달라지는지 위주로
  - 과학 용어 나열 금지
- 톤 예시:
  - "에어젯으로 재생인자를 깊이 전달해요."
  - "열어둔 길에 재생인자를 채워요."
  - "피부가 필요한 걸 직접 넣어주는 단계예요."

### 4. 초음파 (재생인자)
- 역할: 초음파로 침투/마무리하는 장면. 재생인자의 효과를 강조
- 규칙:
  - 1~2문장
  - 재생인자 키워드 자연스럽게 한 번 더
  - 마무리/흡수/안착 느낌
  - 기술 설명보다 결과 체감
- 톤 예시:
  - "초음파로 재생인자가 더 깊이 스며들게 해요."
  - "넣어준 성분이 자리잡도록 초음파로 마무리해요."
  - "피부 깊숙이 재생인자가 안착하는 단계예요."

### 5. 애프터 (후킹 + CTA)
- 역할: 시술 후 변화된 피부를 보여주면서 감탄 후킹 + 댓글 유도
- 규칙:
  - 2~3문장
  - 첫 문장은 변화를 직감적으로 보여주는 후킹
  - 마지막 문장은 반드시 댓글 유도 CTA
  - CTA는 자연스럽게, 강매 느낌 없이
- 후킹 톤 예시:
  - "딱 봐도 다르죠."
  - "와, 이건 진짜 다르다."
  - "이번엔 확실히 달라요."
- CTA 톤 예시:
  - "댓글로 '천방케어' 남겨주세요."
  - "'천방케어' 댓글 남겨주세요."
  - 주의: "궁금하면 댓글로 물어보세요" 같은 막연한 CTA 금지
  - 반드시 구체적 키워드('천방케어')를 댓글로 남기게 유도

## 샘플 대본 1 | 홍조/열감 피부

**[비포]**
이 피부가 이렇게 달라져요.

**[레이저]**
천방케어 레이저로 피부 길을 열어줘요.

**[에어젯]**
열어둔 길에 재생인자를 깊이 채워요.

**[초음파]**
초음파로 재생인자가 피부에 안착해요.

**[애프터]**
와, 이건 진짜 다르다.
열 오르던 피부가 이렇게 편안해졌어요.
이 관리 궁금한 분 댓글 남겨주세요.

---

## 샘플 대본 2 | 예민/장벽 약화 피부

**[비포]**
이번엔 진짜 달랐어요.

**[레이저]**
천방케어 첫 단계, 레이저로 피부에 통로를 만들어요.

**[에어젯]**
에어젯으로 재생인자를 직접 전달해요.

**[초음파]**
초음파로 성분이 자리잡도록 마무리해요.

**[애프터]**
딱 봐도 다르죠.
예민했던 피부가 한결 편안해 보여요.
받아보고 싶은 분?

## 샘플 대본 3 | 탄력/노화 피부

**[비포]**
와, 이건 받고 싶다.

**[레이저]**
천방케어 레이저로 피부가 받아들일 준비를 해요.

**[에어젯]**
피부가 필요한 재생인자를 직접 넣어주는 단계예요.

**[초음파]**
초음파로 재생인자가 더 깊이 스며들게 해요.

**[애프터]**
이번엔 확실히 달라요.
처져 보이던 인상이 정리됐어요.
피부 고민 댓글로 알려주세요.

---

## 샘플 대본 4 | 색소/기미 피부

**[비포]**
이 피부 상태에서 시작했어요.

**[레이저]**
천방케어 레이저로 피부에 길을 열어요.

**[에어젯]**
에어젯으로 재생인자를 채워요.

**[초음파]**
넣어준 성분이 안착하도록 초음파로 마무리.

**[애프터]**
와, 이건 못 참죠.
칙칙했던 톤이 한결 밝아 보여요.
궁금하면 댓글로 물어보세요.

## 작성 체크리스트
- [ ] 비포 후킹이 1~2문장이고 스크롤을 멈추게 하는가?
- [ ] 레이저 파트에 "천방케어" 키워드가 자연스럽게 들어갔는가?
- [ ] 에어젯 파트에 "재생인자/성장인자/10GF" 키워드가 있는가?
- [ ] 초음파 파트에 재생인자 키워드가 한 번 더 나오는가?
- [ ] 애프터 후킹이 변화를 직감적으로 보여주는가?
- [ ] CTA가 댓글 유도이고 강매 느낌이 없는가?
- [ ] 전체 대본이 짧고 살아있는 구어체인가?
- [ ] 과장/의료 오해 표현이 없는가?
- [ ] WIIFM이 살아있는가? (고객이 받고 싶어지는가?)
