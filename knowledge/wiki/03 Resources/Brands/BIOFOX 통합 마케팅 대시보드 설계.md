# BIOFOX 통합 마케팅 대시보드 설계

## 개요
BIOFOX 전용 커스텀 웹앱. 퍼널 전체를 한 곳에서 보고, 데이터 기반 의사결정, 광고 직접 조작까지.

## 화면 구조

### 화면 1: 퍼널 오버뷰
- 유튜브 조회 → 유입 → 카카오 추가 → 상담 → 전환 → 리텐션
- 각 단계 숫자 + 전환율 + 전주 대비 증감
- 병목 즉시 파악

### 화면 2: 채널별 상세
- PPT채널 / 애니채널 / 오피셜 / 인스타 / 블로그
- 콘텐츠별 성과, UTM 기반 유입 추적

### 화면 3: 광고 관리
- 메타/구글 광고 통합
- 캠페인 성과 (CPC, CTR, ROAS)
- 예산 조정, 켜기/끄기, 소재 교체 직접 실행

### 화면 4: 리타겟 시나리오
- 퍼널 이탈 지점별 리타겟 시나리오 관리
- 시나리오별 성과 + 수정/중지/소재변경

### 화면 5: AI 인사이트 (Phase 후반)
- 데이터 기반 자동 제안

## 데이터 소스
- GA4 API → 홈페이지 데이터
- Meta Marketing API → 광고 + 픽셀
- YouTube Analytics API → 채널 데이터
- Kakao API → 채널 추가/메시지

## 기술 스택 (미확정)
- 프론트: Flutter 웹 or React/Next.js
- 백엔드: n8n 수집 자동화 → DB → 앱
- 선행 작업: GTM/GA4/메타픽셀 설치

## 개발 Phase
1. GTM/GA4/메타픽셀 설치 + 데이터 수집 시작
2. 퍼널 오버뷰 대시보드
3. 채널별 상세
4. 광고 관리
5. 리타겟 시나리오
6. AI 인사이트
