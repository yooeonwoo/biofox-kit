# BIOFOX 후킹형 블로그 기법

## 목적
BIOFOX 네이버 블로그 작성 시 후킹형 기법의 기준 노트.
자청(한국 마케팅) + 세계적 카피라이팅 대가(Schwartz, Sugarman, Halbert, Ogilvy) 기법을 통합.

## 왜 기존 블로그가 뻔했나

### 시장 정교화 5단계 (Eugene Schwartz)
1단계: 최초 주장 ("이 크림이 기미를 없앱니다")
2단계: 주장 확대 ("14일 만에")
3단계: 메커니즘 ("재생인자가 피부 안쪽에서...")
4단계: 메커니즘 확대 ("에어젯으로 직접 넣어서...")
5단계: 아이덴티티 ("뭘 해도 안 됐던 사람들을 위한 관리")

**피부관리 시장은 이미 5단계.** 주장도 메커니즘도 후기도 다 봤다.
근데 우리는 3~4단계 글(메커니즘 설명)을 쓰고 있었다.
5단계에서는 아이덴티티와 스토리로 진입해야 한다.

### 기존 글의 문제점
- 직선 구조 (문제→악화→해결→후기→CTA) = 예측 가능
- 반박제거가 Q&A 형태로 노출 = 설득 구조 감지됨
- 후킹이 "공감형/질문형" 한 가지뿐
- 고객 사례가 하나의 긴 스토리 = 클리셰화
- 천방케어 메커니즘 설명 반복 = 3단계 글

## 후킹 기법 라이브러리 (6종)

### 1. 콜드 오픈 (In Medias Res)
장면 한가운데에서 시작. 서론/배경 없음.
- "상담 끝나고 고객님이 안 가셨어요."
- "카톡이 왔는데, 사진 한 장이었어요."
출처: TV/영화 cold open 기법. Nicolas Cole, Tim Denning 등 활용.

### 2. 하나의 이상한 디테일 (Specificity Hook)
구체적이고 예상 못한 디테일 하나로 시작.
- "43세 고객님의 메모장에 420만원이 적혀 있었어요."
Gary Halbert: "구체성이 신뢰의 영혼이다."
George Loewenstein의 정보 격차 이론 — 이상한 디테일이 궁금증 폭발.

### 3. 고백 훅 (Confession Hook)
권위가 아니라 실패/약점으로 시작.
- "솔직히 저도 이 관리에 확신이 없었어요."
Rory Sutherland (Ogilvy 부회장): 약점 인정 = 정직함의 costly signaling.

### 4. 선언 훅 (Declaration Hook)
질문 아니라 단정으로 시작.
- "톤업크림은 위장입니다."
Schwartz: 독자 머릿속 대화에 반대편으로 진입. 동의든 반발이든 읽게 됨.

### 5. 타임스탬프 훅
구체적 시간으로 시작.
- "수요일, 오후 3시. 관리 끝나고 고객님이 울었어요."
저널리즘/범죄수사물 기법. 뇌가 "마케팅"→"사건 목격"으로 전환.

### 6. 속삭임 훅 (Anti-Hype)
의도적 절제. 과장의 바다에서 조용함이 패턴 인터럽트.
- "재미없는 글이에요. 근데 기미 때문에 돈 쓴 적 있으면 읽어보세요."
Ogilvy 롤스로이스 광고: "시속 60마일에서 가장 큰 소음은 전자시계 소리."

## 구조 기법

### 비선형 구조 (직선 구조 금지)
```
콜드 오픈 → 오픈 루프 A → 자아흠집/아이덴티티 → 벨벳 로프
→ 치명적 인정 → 천방케어 제안(최소) → 마이크로 스토리 스택
→ 오픈 루프 A 닫기 → 미래 투사 → 손실 회피 + CTA
```

### 오픈 루프 캐스케이드 (Joe Sugarman)
- 글 초반에 궁금증 열고 후반에 닫기
- "이분 얘기는 좀 이따 다시 할게요."
- 여러 루프를 열어서 TV 드라마처럼 긴장감 유지
- Zeigarnik Effect — 미완성 패턴에 뇌가 집착

### Slippery Slide (Joe Sugarman)
- 모든 문장의 유일한 목적 = 다음 문장 읽게 하기
- 첫 문장은 짧을수록 좋다
- 100-150자마다 미니 클리프행어
- 문단 끝을 절대 완결짓지 않기

### 마이크로 스토리 스택
- 한 명의 긴 사례 대신 짧은 사례 3-4개 쌓기
- 각 2-3줄. 이름(가명) + 상황 + 체감 한 줄.
- 여러 사례 쌓임 = 통계 없이도 증거

## 설득 기법

### 치명적 인정 (Damaging Admission — Ogilvy/Halbert)
- 단점/한계 먼저 인정 → 나머지 장점 신뢰도 상승
- "기미가 사라진다고 약속할 수 없어요."
- Q&A 형태 금지. 서사 안에 자연스럽게 녹이기.

### 반박제거 서사 내장형
- "에이 그래서 뭐?" 식 Q&A 반복 금지
- 최대 2개, 서사에 녹이기
- "이 말만 하면 또 레이저 아니냐고 하실 거잖아요. 그래서 사례를 보여드릴게요."

### 벨벳 로프 (Eugene Schwartz)
- 읽는 사람을 특별한 그룹으로 만들기
- "이 상황이면 계속 읽으세요. 아니면 나가셔도 돼요."
- 계속 읽는 사람 = 정체성 부여

### 미래 투사 (Future Pacing — Sugarman + NLP)
- 결과 설명 X → 결과 이후의 아침 묘사 O
- "거울 앞에 서는 시간이 달라지고, 가리는 에너지가 줄고"
- 감각적이고 구체적인 일상 장면

### 손실 회피 (Schwartz)
- "지금까지 한 방법이 효과 있었으면 여기까지 안 읽었을 거예요."

## 자청 스타일 요소 (선택적 활용)

### 핵심 구조
후킹 → 자아흠집내기 → 권위부여 → 해결책 → 행동유도

### 본능분석 5가지 트리거
- 생존 본능, 사회적 증거, 손실 회피, 호기심, 권위

### 반박제거 3단계
- 예측 → 우선순위 → 제거 (선제적/데이터/스토리)

### 주의
- 자기계발 톤("뇌근력", "매일 성장") 사용 금지
- 과도한 자기 이야기 금지 (원장 블로그에선 고객이 중심)
- 과도한 권위부여 금지 (에스테틱에선 거부감)

## 대가 레퍼런스 요약

| 대가 | 핵심 기법 | 우리 적용 |
|------|----------|----------|
| Eugene Schwartz | 시장 정교화 5단계, 인지도 5단계 | 5단계 진입(아이덴티티/스토리) |
| Joe Sugarman | Slippery Slide, Seeds of Curiosity | 오픈 루프, 문장 연결 |
| Gary Halbert | 구체성=신뢰, Starving Crowd | 구체적 숫자/디테일 |
| David Ogilvy | 절제, Damaging Admission | 치명적 인정, 속삭임 훅 |
| 자청 | 후킹→자아흠집→권위→해결 | 구조 참조, 톤은 우리식 |
