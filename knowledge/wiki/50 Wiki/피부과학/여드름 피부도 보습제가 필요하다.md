# 여드름 피부도 보습제가 필요하다

## Main Idea
여드름 피부는 기름이 많아 보이지만 실제로는 보습이 잘 되지 않는 부위를 의미한다. 보습제를 발라주면 보습 기능이 어느 정도 유지되어 피지를 많이 분비하지 않아도 되게 되어 여드름이 개선되는 케이스가 많다.

## Context
