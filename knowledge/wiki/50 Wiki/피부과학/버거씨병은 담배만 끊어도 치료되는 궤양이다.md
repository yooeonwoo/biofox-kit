# 버거씨병은 담배만 끊어도 치료되는 궤양이다

## Main Idea
버거씨병(Buerger's disease)은 흡연이 직접적 원인인 대표적인 궤양성 질환이다. 담배가 말초혈액순환을 방해해 동맥성 궤양을 유발하는데, 금연만으로도 극적인 호전을 보이는 경우가 많다.

## Context
흡연자에게 발생하는 하지궤양의 대표적 질환으로, 생활습관 교정의 중요성을 보여주는 사례다.
