# 큐어부스터 노화편은 라이트쿼터 홍조편의 샷 구조를 그대로 따른다

큐어부스터 노화편은 별도의 얼굴 파열 영상이 아니다. 기존 라이트쿼터 홍조편의 **동상 단독 → 제품 단독 → 정상 분사 → 입자 이동 → 볼 충돌 → 외피 박리 → 인간 애프터** 구조를 그대로 유지하고, 피부 고민만 노화로 바꾼다.

## 정확한 키프레임 순서

1. 따뜻한 신고전주의 살롱의 전신 노년 대리석 동상
2. 눈을 감은 노년 대리석 동상 얼굴 클로즈업
3. BIOFOX REVERSE-AGING CURE BOOSTER Light Quarter 제품 단독
4. 캡이 열린 라이트쿼터와 노즐 구멍 중심에서 정상 분사되는 미스트
5. 투명한 진주 입자가 노년 대리석 동상을 향해 이동
6. 진주 입자가 노년 대리석 볼에 닿으며 인공 광물 외피 파열 시작
7. 넓은 노년 대리석 외피 아래 젊은 피부 노출
8. 반 노년 대리석 동상·반 젊은 새 모델
9. 완전히 젊어진 새 모델 애프터

## 모델과 제품 권한 분리

새 모델 사진은 얼굴형, 눈·눈썹, 코, 입술, 턱, 긴 검은 머리의 **정체성만** 제공한다. 검은 민소매 의상, 회색 배경, 붉은 조명, 원본 카메라 각도는 사용하지 않는다. 구도, 세트, 그리스식 드레스와 샷 역할은 기존 라이트쿼터 영상이 권한을 가진다.

03과 04는 제품 왜곡을 막기 위해 기존 영상에서 검증된 Light Quarter 제품 단독·정상 분사 프레임을 그대로 사용한다. 04의 미스트는 흰색 액추에이터 정면의 작은 원형 노즐 구멍 중심에서 시작한다.

젊은 피부가 나타나는 06–09는 좋은 피부 상태와 리얼리즘을 동시에 유지한다. 코·안쪽 볼의 미세 모공, 모낭, 솜털, 약한 톤 변화, 작은 주근깨, 눈 밑의 얇은 주름, 홍채 섬유와 눈물막을 남기고 `unretouched skin`, `raw skin surface`, `no smoothing`, `no digital retouching`, `real photograph, not rendered`를 적용한다. 단, 라이트쿼터의 밝은 럭셔리 광고이므로 과장된 땀·먼지·심한 잡티·붉은기·번들거림은 제외한다.

## 노화 은유

약 75세 얼굴 구조를 새긴 카라라 대리석 외피가 벗겨지며, 그 아래에 원래 존재하던 현재의 젊은 모델이 드러난다. 깨지는 것은 인공 광물 외피뿐이고, 사람 피부는 상처 입지 않는다. 건조 균열망, 작은 비늘, 피, 조직, 먼지 폭발은 금지한다.

## Seedance 2.5 체인

9개 키프레임을 8개의 first/last-frame 클립으로 연결한다. 각 클립은 4초·720p·무음·워터마크 없음으로 생성하고, 실제 디코딩 마지막 프레임을 `GetVideoComponents`와 `ImageFromBatch(-1)`로 추출해 다음 클립의 첫 프레임으로 사용한다. 생성량은 실행 시 총 32초이며, 편집 단계에서 기존 라이트쿼터 영상과 동일한 9초 리듬으로 압축하고 마지막 애프터를 0.5초 유지한다.

최종 클립은 노년 대리석 외피가 제거되는 동안 얼굴 구조를 고정하고, 마지막 프레임의 양쪽 아몬드형 눈을 자연스럽게 연 채 카메라에 초점을 맞추도록 지시한다. 피부는 모공·솜털·미세질감을 유지하며 눈꺼풀 처짐·빈 시선·뷰티필터를 금지한다.

1번 줌 영상은 독립 생성된 시작·끝 동상의 얼굴과 방 구조가 달라 전체가 변형되는 문제가 있었다. 끝 프레임을 시작 프레임의 동일 픽셀 크롭으로 교체하고 프롬프트를 `rigid frozen photograph`, `pixel-locked`, `no parallax`, `no depth morph`로 강화했다. 최종 1번 영상은 생성형 모델 대신 smoothstep 기반의 결정적 2D 줌으로 렌더해 동상·의상·건축·조명이 바뀌지 않는다. 교정본은 `output/clips/01_statue_wide_to_close.mp4`다.

최종 조립에서는 2번 영상을 제외하고 `01 → 03 → 04 → 05 → 06 → 07 → 08` 순서로 디졸브 연결했다. 각 소스의 정지 꼬리와 08의 첫 0.95초 정지를 제거한 뒤 전체를 1.2배속으로 렌더했다. 최종본은 18.833초, 720×1280, H.264, 30fps, 무음이며 최대 근정지 연속 구간은 1프레임(0.033초)이다. 파일은 `~/Downloads/cure_booster_aging_final_omit02_dissolve_1p2x.mp4`다.
