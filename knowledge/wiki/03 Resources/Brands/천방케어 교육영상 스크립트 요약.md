# 천방케어 교육영상 스크립트 요약

## 원본
- 페이지: 19p
- 성격: 원장 상담/교육용 스크립트

## 다루는 고민 주제
- 기미 / 색소침착
- 홍조 / 모세혈관 확장
- 모공 / 피지 과다
- 주름 / 노화
- 여드름 / 염증성 피부
- 한관종

## 천방케어의 공통 서사 구조
모든 스크립트가 거의 같은 구조를 가진다.

1. 고객 고민 정의
- 해당 피부 고민이 무엇인지 쉽게 설명

2. 원인 설명
- 자외선, 열, 염증, 스트레스, 피지, 노화 등 원인을 풀어줌

3. 기존 케어의 한계
- 레이저, 필링, 단기 진정, 일시적 억제의 한계를 제시

4. EGF / FGF 근거 제시
- 피부 장벽, 표피 재생, 진피 강화, 염증 억제, 기저막/혈관벽/콜라겐 관련 설명

5. 천방케어 제안
- 어븀야그 프락셔널 레이저로 미세 통로를 만들고
- 에어젯으로 10GF를 피부에 전달하는 구조

6. 고객 설명 문장 제공
- 원장님이 상담 때 그대로 쓸 수 있는 표현 제공

## 천방케어의 브랜드 해석
천방케어는 단순 진정 관리가 아니라,
"문제 피부를 근본적으로 덜 흔들리는 피부 컨디션으로 바꾸는 관리"로 포지셔닝되어 있다.

핵심 메시지:
- 10GF 기반
- EGF / FGF 중심 설명
- 어븀야그 프락셔널 레이저 + 에어젯 전달
- 단기 완화보다 근본 컨디션 개선 서사

## 고민별 포지셔닝 포인트
### 기미
- 멜라닌 과잉 생성과 기저막 약화를 문제로 설명
- 기존 레이저/필링은 재발과 구조 손상 한계를 가진다고 설명
- 천방케어는 멜라닌 문제와 피부 구조 건강을 같이 본다는 서사

### 홍조
- 혈관 확장, 염증, 외부 자극, 스트레스를 원인으로 설명
- 단순 쿨링/혈관레이저의 한계 대비
- 장벽 강화와 혈관벽 안정화 쪽 논리로 전개

### 모공
- 피지 과다 + 탄력 저하 복합 문제로 설명
- 콜라겐 강화와 피지 밸런스 논리를 같이 씀

### 주름/노화
- "피부재생인자 감소증"이라는 표현을 사용하며 노화를 재생력 저하로 해석
- 성장인자 부족을 보완하는 관리로 포지셔닝

### 여드름
- 염증, 과각화, 피지, 생활습관까지 연결
- 단순 압출/건조 관리보다 장벽과 염증 조절 서사가 강함

### 한관종
- 민감한 문제를 다루되 직접 치료 언어 대신 피부 상태 이해와 관리 논리로 접근

## 상담형 문장으로 바꿨을 때의 강점
이 자료의 진짜 강점은 과학 설명이 아니라,
원장님이 고객 상담에서 "왜 이 관리를 해야 하는지"를 길게 설명할 논리를 준다는 점이다.

즉, 천방케어는
- 비포애프터 자랑형 관리보다
- 원인 설명형 상담에 강하고
- 고가 관리 설득에 유리한 구조를 가진다.

## 릴스 대본에 적용할 때 번역 규칙
교육자료의 원문은 다소 길고 학술적이다.
릴스에서는 아래처럼 번역하는 게 맞다.

- 기미를 없앤다 → 색소가 반복적으로 올라오는 피부 환경을 관리한다
- 홍조를 해결한다 → 쉽게 붉어지는 피부 컨디션을 덜 흔들리게 돕는다
- 모공을 줄인다 → 늘어진 모공이 더 도드라져 보이지 않게 피부 컨디션을 정리한다
- 주름을 개선한다 → 탄력 저하로 무너진 인상을 관리한다

## 폭시/광고 문구 주의와 연결
원문에도 "기미는 의학적 용어이므로 광고하실 때는 주의가 필요하다. 폭시를 이용해달라"는 취지의 문장이 등장한다.
따라서 천방케어 관련 릴스는
- 상담용 내부 설명
- 대외용 광고 표현
을 분리해서 운영해야 한다.
