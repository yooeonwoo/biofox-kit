# 유튜브 대본 1개를 마스터 원고로 설계하면 16~18개 자산으로 OSMU 파생이 가능하다

## Main Idea
대본을 처음부터 OSMU용으로 설계한다. 유튜브 풀영상 → 숏폼(릴스/숏츠/틱톡) → 블로그(네이버/브런치) → 카드뉴스(인스타) → 카페/커뮤니티 발췌 → 뉴스레터. 1개 마스터 원고에서 16~18개 채널별 자산이 나온다. pyCapCut 같은 도구로 영상 편집 파이프라인 자동화도 가능.

## Context
BIOFOX처럼 소수 인원 팀이 멀티채널을 운영하려면 콘텐츠 재활용이 필수. 핵심은 대본 단계에서 파생을 염두에 두는 것.
