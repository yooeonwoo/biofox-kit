# 피부 노화는 재생인자 부족증이다

## Main Idea
피부 노화의 본질은 EGF/FGF(피부 재생 인자)의 체내 생성량 감소다. 이것은 공식(기전)이다.

- 성장호르몬 부족 → 키가 안 큼
- 인슐린 부족 → 당뇨
- 피부 재생 인자 부족 → 피부 노화

20대 중반부터 생성량이 줄어든다. 따라서 재생인자를 외부에서 공급하면 젊어지고, 나이가 많을수록(노화된 세포가 많을수록) 효과가 더 빠르게 나타난다. 이 역설이 BIOFOX의 강력한 셀링포인트.

## Context
유튜브 콘텐츠에서 "왜 40대부터 확 늙는가" 류의 주제를 다룰 때, 결론은 항상 이 공식으로 귀결된다. 단, 직접 "EGF를 사세요"가 아니라 "재생인자가 부족해서 그렇다"는 인식을 심어주는 것이 목표.
