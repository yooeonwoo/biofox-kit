# AI식 친절 비유 클리셰는 직설 설명을 한 번 더 풀어쓰는 잉여다

## Main Idea
AI가 콘텐츠를 쓸 때 가장 자주 나오는 군더더기는 '직설 설명 + 일상 비유 풀이'의 중복 구조다. '~인 거예요. 쉽게 말하면 ~ 같은 거예요', '~ 하는 거랑 비슷한 일이 ~', '~로 보면 ~인 셈이에요' 형태로 메커니즘을 직설로 말한 뒤 굳이 비유로 다시 푼다. 식상한 비유 카탈로그(옷/바람, 주방/요리, 공장/자재, 자동차/도로, 택배/배달, 매니저)가 하나라도 등장하면 자동 감점. 비유에 따옴표를 붙여 라벨링하는 것('피부 전용 택배'처럼)도 금지. 직설로 충분하면 거기서 끝내고, 비유 없이 직접 묘사로 풀어쓴다.

## Context
BIOFOX 영상 대본을 AI로 생산할 때 톤을 망치는 1순위 패턴. 직설 설명이 이미 충분한데 비유를 덧대면 분량만 늘고 신뢰가 떨어진다. 사후 체크리스트로 잡아내야 하는 대표적 AI 슬롭이다.
