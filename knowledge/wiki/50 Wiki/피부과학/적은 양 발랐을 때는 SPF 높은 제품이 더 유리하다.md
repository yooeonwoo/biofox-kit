# 적은 양 발랐을 때는 SPF 높은 제품이 더 유리하다

## Main Idea
실제 사용량이 권장량보다 적을 때, SPF가 높은 제품일수록 더 나은 자외선 차단 효과를 보인다. 적은 양으로도 SPF 30과 50의 실제 차단능력에는 차이가 있다.

## Context
대부분 사람들이 권장량보다 적게 발라서 실제 SPF 수치보다 낮은 보호효과를 받는다.
