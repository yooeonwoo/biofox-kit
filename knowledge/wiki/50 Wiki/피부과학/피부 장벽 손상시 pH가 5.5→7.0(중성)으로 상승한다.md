# 피부 장벽 손상시 pH가 5.5→7.0(중성)으로 상승한다

## Main Idea
건조한 피부, 아토피 피부염, 홍조가 있는 경우 피부 표면 pH가 약산성(5.5)에서 거의 중성(7.0)까지 올라간다. 이때 해로운 세균들이 잘 살게 되어 피부 표면 세균 감염이 많아진다.

## Context
pH 상승은 피부 장벽 기능 저하의 신호이자 결과물이다.
