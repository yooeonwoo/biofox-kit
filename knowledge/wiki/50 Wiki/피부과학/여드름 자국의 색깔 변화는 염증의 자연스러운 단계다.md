# 여드름 자국의 색깔 변화는 염증의 자연스러운 단계다

## Main Idea
모든 염증은 붉은색 → 검붉은색 → 검정색 순서로 변하면서 서서히 없어진다. 붉은 자국은 빈 공간이 차오르는 중간 과정이고, 검정 자국은 염증 후 색소침착이다. 시간이 지나면서 이것들이 흉터로 바뀐다.

## Context
자국의 색깔별로 다른 치료 접근이 필요하며, 조기 치료가 흉터 예방의 핵심이다.
