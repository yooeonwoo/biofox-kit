# BIOFOX n8n 캡션·블로그 자동화 구조

## 개요
Flutter 앱(폭시)에서 Webhook으로 요청을 보내면, n8n 워크플로우가 인스타그램 캡션 또는 블로그 포스트를 자동 생성하는 파이프라인.
광고법·화장품법·의약품법 컴플라이언스를 프롬프트 레벨에서 강제한다.

## 워크플로우 아키텍처

```
[Flutter App] → [Webhook POST]
                    ↓
              [Text Classifier] ── 인스타 ──→ [AI Agent: 캡션 생성] → [AI Agent2: 검수] → [Response]
                    │
                    └── 블로그 ──→ [Code: 전처리] → [AI Agent5: 스토리 추출]
                                                          ↓
                                                  [Text Classifier1: 블로그 타입 분류]
                                                          ↓
                                        ┌─ 후기형(감정공감)
                                        ├─ 후기형(지적호기심)
                                        ├─ 걱정유발형(두괄식)
                                        ├─ 체험단형(과정중심)
                                        └─ 체험단형(결과중심)
                                                          ↓
                                                    [Response]
```

## Webhook 입력 데이터
```json
{
  "body": {
    "type": "generate",
    "data": {
      "platform": "인스타그램" | "블로그",
      "age": "20대~60대 이상",
      "gender": "여성 | 남성 | 전체",
      "concern": "피부 고민 카테고리",
      "message": "고객과의 에피소드",
      "phone": "문의 전화번호",
      "region": "지역명",
      "shop_name": "샵명",
      "blog_type": "후기형V1 | 걱정유발형 | 체험단형V1" (블로그 전용)
    }
  }
}
```

### concern 카테고리
- 붉음증 / 예민 피부 / 얇은 피부
- 모공 / 요철 / 각질
- 노화 / 주름 / 탄력
- 색소 (기미·잡티) / 미백
- 여드름 / 아토피 / 건선 / 흉터

## 파이프라인 1: 인스타그램 캡션

### Agent 1 — 캡션 생성
**역할**: concern 카테고리에 맞는 후킹 문구 선택 → 고객 에피소드를 녹인 감성 캡션 작성

**핵심 규칙**:
- 첫 80자 이내에 "천방케어" 필수
- 캡션 300–400자
- "천방케어" 3회 이상, "바이오폭스" 1회
- 모든 호칭 → "고객님"으로 통일

**캡션 구조** (300–400자):
1. 도입부 (50–80자): 후킹 문구 + 에피소드 묘사
2. 전환부 (50–70자): 에피소드→천방케어 연결, 공감
3. 핵심 (150–200자): 피부 변화 과정, 고객 반응, 바이오폭스 1회
4. 마무리 (80–100자): 필수 CTA 형식

**필수 마무리 형식**:
```
💬문의: {전화번호}
🔎네이버 '{샵명}' 검색
✅{샵명} 상담이 필요하다면 저장 및 댓글 남겨주세요
🆗비슷한 피부로 고민하고 있는 지인에게 공유해주세요
```

**필수 각주**:
```
※ 천방케어는 MICROJET 기기를 이용하여 BIOFOX의 10-GF 성분을 흡수시키는 에스테틱 관리 프로그램의 명칭입니다.
※ 주름개선/미백 효과는 주름개선/미백 이중기능성을 획득한 BIOFOX 제품에 한한 내용입니다.
※ MICROJET 미용기기는 BIOFOX 제품의 흡수를 도와주는 목적으로만 사용됩니다.
```

**카테고리별 해시태그**:
- 공통 필수: #천방케어 #마이크로젯 #바이오폭스
- 붉음증/예민: #예민피부 #민감성피부 #진정케어 #편안한피부 #피부진정
- 모공/요철/각질: #매끈피부 #피부결케어 #모공관리 #깐달걀피부
- 노화/주름/탄력: #탄력케어 #안티에이징케어 #피부탄력 #탄탄한피부
- 색소/미백: #맑은피부톤 #톤케어 #광채피부 #환한피부
- 여드름/아토피/건선/흉터: #피부고민 #예민한피부 #피부진정 #깨끗한피부
- 지역 필수: #[지역]에스테틱 #[지역]피부관리 #[샵명]

### Agent 2 — 컴플라이언스 검수
**역할**: 생성된 캡션의 금지 표현을 잡고 안전 표현으로 교체

**검수 체크리스트**:
1. 질병명 직접 언급 금지 → 아토피, 여드름, 기미, 건선, 흉터, 홍조, 트러블 등
2. 의학적 효능 암시 금지 → 치료, 개선, 해소, 탈출, 완화, 제거, 축소, 침투, 역노화 등
3. 의료 행위 암시 금지 → 시술, 주사, 주입, 리프팅, ~해드려요, 펴드려요 등
4. 병원/피부과/의원 언급·비교 절대 금지
5. 해시태그에도 금지 표현 포함 불가

**최종 출력 형식** (파싱용 라벨 고정):
```
[후킹문구]
천방케어 후킹문구

[캡션]
검수된 캡션 내용

[해시태그]
#천방케어 #마이크로젯 #바이오폭스 #기타해시태그

------
※ 각주 3줄
```

## 파이프라인 2: 블로그

### 전처리 Code 노드
JavaScript로 민감 단어를 사전 제거/치환:
- **삭제 대상**: 여드름자국, 흉터, 혈관, 모세혈관, 의학적, 임상, 치유, 완치, FDA, 부작용, 피부과, 박사, 교수, 아토피, 자국
- **치환 대상**: 병원→다른 곳, 치료→관리, 시술→관리, 레이저→관리, 주사→관리, 약→제품, 리프팅→탄력 관리, 흉터→피부 고민

### AI Agent5 — 스토리 추출
전처리된 메시지를 자연스럽게 다듬고 스토리 요소를 JSON으로 추출:
- emotion_arc (감정 변화 곡선)
- key_episodes (핵심 에피소드 3개)
- story_type (family/event/confidence/change)
- tone_elements (연령대별 어투)
- final_safety_check

### Text Classifier1 — 블로그 타입 분류
5종 블로그 타입으로 라우팅:
1. **후기형 1인칭 - 감정공감형** (review_emotional)
2. **후기형 1인칭 - 지적호기심형** (review_intellectual)
3. **걱정 유발형 - 두괄식** (concern_direct)
4. **체험단형 3인칭 - 과정중심** (experience_process)
5. **체험단형 3인칭 - 결과중심** (experience_result)

### 블로그 공통 규칙
- 글자수: 1300자 (±50자)
- 이미지 위치 6곳 표시: `(이미지: 설명 - alt: "설명")`
- 지역명 + 샵명 3–4회 자연스럽게 노출
- 천방케어 설명: "바이오폭스 10GF를 마이크로젯으로 흡수시키는 에스테틱 관리 프로그램"
- 효과/통증은 고객의 말로만 간접 전달
- "피부 재생" → "피부 자생"
- "마이크로젯 기기/기술" → "마이크로젯으로/마이크로젯이"

**주의사항 안내 (필수)**:
- 당일 세안 절대 금지
- 선크림 당일 사용 금지
- 큐어부스터 10분마다 뿌리기

**하단 고정 문구**:
```
※ 천방케어는 MICROJET으로 BIOFOX 10GF의 흡수를 돕는 에스테틱 관리 프로그램입니다.
※ 10GF는 FGF Complex의 프로덕트 네임입니다.
※ 마이크로젯은 흡수를 도와줍니다.
※ BIOFOX 10GF는 주름 개선 개별고시형 인증을 받았습니다.
※ 개인차가 있을 수 있습니다.
```

### 블로그 타입별 특징

| 타입 | 시점 | 핵심 특징 | 구조 |
|------|------|----------|------|
| 감정공감형 | 원장 1인칭 | 따뜻한 전문가, 감동 스토리 | 첫 만남→공감→천방케어→변화→지속변화→마무리 |
| 지적호기심형 | 원장 1인칭 | 3–4주 관찰 분석, 전문적 | 케이스소개→초기분석→1회차→2-3회차→3-4회차→의견 |
| 걱정유발형 | 원장 1인칭 | 두괄식, 위기감→희망 | 충격도입→불편한 진실→공감→희망전환→증거→행동유발 |
| 과정중심 | 고객 3인칭 | 일기형, 시간순 | 방문계기→첫방문→1회차→2회차→3회차→정리 |
| 결과중심 | 고객 3인칭 | 파워리뷰어, B/A 비교 | 총평+별점→Before→과정→After→장단점→가성비→추천 |

## 컴플라이언스 핵심 요약 (공통)

### 호칭 변환
모든 호칭 → "고객님" (할머니, 아줌마, 학생, 아가씨, 사모님 등)
예외: 예비신부 → "예비신부 고객님"

### 금지 표현 → 우회 표현

| 금지 | 대체 |
|------|------|
| 역노화/리버스에이징 | 젊어지는 피부 / 시간을 되돌리는 |
| 홍조 | 붉고 예민해지는 피부 |
| 기미 | 칙칙한 피부 |
| 여드름 | 갑자기 올라오는 울긋불긋함 |
| 아토피 | 예민하고 가려운 피부 |
| 리프팅 | 탄력 있는 피부 |
| 모공 축소 | 매끈해지는 피부결 |
| 미백 | 맑고 환한 피부톤 |
| 재생/피부재생 | 피부에 활력을 더하는 / 피부 자생 |
| 치료/시술/주사 | 케어/관리/천방케어 |
| 침투 | 흡수/도포/전달 |
| 병원/피부과/의원 | (언급·비교 자체 금지) |
| 셀프케어 | 천방케어/전문 관리 |
| 트러블 | 울긋불긋한/올라오는/예민한 피부 |

### 절대 금지
- 질환명 직접 언급
- "해결", "치료", "개선", "탈출", "제거" 등 의료 행위 암시
- 병원·피부과·의원 언급 또는 비교
- "~해드려요", "펴드려요" 등 시술 암시
- 과장 표현 (완벽, 기적, 100%)
- 구체적 수치 + 젊어보인다 ("10년은 젊어 보여요" → "확실히 젊어 보여요")
