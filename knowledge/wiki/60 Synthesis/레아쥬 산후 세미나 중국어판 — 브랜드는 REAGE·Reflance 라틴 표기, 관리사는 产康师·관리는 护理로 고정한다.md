# 레아쥬 산후 세미나 중국어판 — 용어·표기 결정 기록

**질의**: 『레아쥬 산후 회복 테라피 세미나』 덱 20장(2026-09-10, 중국 산후회복센터 원장 22명 초청, 통역 동반 60분)을 레이아웃 그대로 중국어(간체)로 바꾸고, 슬라이드 노트 기반 발표 대본을 슬라이드당 1페이지 중국어 문서로 만들 때 무엇을 어떻게 고정했는가.

## 결정 1 — 브랜드·조직명은 라틴 표기, 한자 창작 금지
- 레아쥬 → **REAGE** (reage.co.kr 공식 영문), 리플런스 → **Reflance** (reflance.co.kr). 공식 중국어 상호가 없으므로 한자 음역을 지어내지 않는다. 덱 커버의 `RE-AGE THERAPY`는 원문 유지.
- LS항노화센터 → LS抗衰老中心. ETJ (Energy Therapy Japan) 官方合作伙伴.
- 한국 인명 4건은 한자 추정치라 **발표 전 본인 확인 필요**: 이현→李贤, 이정선→李贞善, 조예나→赵艺娜, 김아람→金娥岚. 직함은 所长/副所长/代表/教育总监.

## 결정 3 — 검수(별도 에이전트)에서 잡힌 오역 패턴 = 다음 번 자가 점검 항목
1. **주어 반전**: 「사람마다 결과가 달라」→ 因人而异는 *고객마다*로 읽힌다 → 效果因操作者而异. 한국어의 생략된 주어를 중국어에서 반드시 복원.
2. **报告了…的趋势** 같은 한국어 문형 직역 → 有研究报告，最高可增加 500%.
3. **한자 훈독 찌꺼기**: 「기운을 채운다 · 補」→ 补气 · 进补 (補를 그대로 두면 낙자처럼 보임).
4. **일본식·한국식 명사 적층**: 抗衰老身体理疗专业企业 → 专业抗衰老身体理疗企业, 构成 → 组合, 崩解(제약 용어) → 分解.
5. **두 줄 제목의 어절 끊김**: 信号传递 / 到肌肉처럼 조사가 다음 줄에 걸리면 把信号 / 传递到肌肉로 재분절.
6. **시연 방향**: 「한 분 또는 두 분께 직접 보여드릴」= 원장에게 *해 드리는* 시연 → 为她们做一次实际体验演示.

## 결정 4 — 레이아웃·대본 규칙
- 중국어는 한국어 대비 글자 수가 25~35% 줄어 폭 초과는 사실상 없었다. 유일한 위험은 wrap 없는 짧은 배지(水肿 OUT, 날짜 캡슐)라 공백 제거로 해결.
- 이미지 안 한국어(14장 자율신경 차트)는 PIL로 라벨만 덧그려 自主神经平衡分析/放松量/活动量/健康度 高·低로 현지화. 4·18장의 사진 속 한글·일본어 스티커는 사진 원본이라 그대로 둠.
- 대본: 노트가 2~20장에만 있었고 1장은 새로 씀. 슬라이드 썸네일 + 본문 11pt, A4 1장/슬라이드, 총 20p 검증. 무대 지시는 [停顿]·[指向图表] 대괄호.
- 제작 파이프라인·LibreOffice 폰트 폴백 함정은 Claude Code 메모리(`pptx-translation-pipeline`)에 기록.
