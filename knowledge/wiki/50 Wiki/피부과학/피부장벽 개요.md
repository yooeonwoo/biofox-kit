# 피부장벽 개요

> 피부과학 위키 1923개 원자노트의 **중심 허브**. 거의 모든 노트가 이 페이지를
> 가리킨다(인바운드 1900+). 전체 지도는 [[MOC - 피부과학]] 참조.

## 한 줄 정의

피부장벽(skin barrier)은 각질층의 벽돌(각질세포)과 시멘트(세포간지질)로 이루어진
물리·화학·면역 방어막이며, 대부분의 피부 문제(건조·홍조·아토피·여드름·색소침착·노화)는
**장벽 기능 저하**라는 공통 뿌리로 수렴한다.

## 장벽 중심으로 본 피부 문제 (수렴 지도)

- **건조·속건조** — 장벽 손상 → TEWL(경피수분손실) 증가. → [[MOC - 피부과학#§보습]]
- **홍조·주사** — 장벽 약화 → 혈관 노출/확장. → [[MOC - 피부과학#§홍조]]
- **아토피·알레르기** — 장벽 결손 → 항원 침투. → [[MOC - 피부과학#§염증·아토피]]
- **여드름·피지** — 장벽 저하가 피지 과분비를 부른다. → [[MOC - 피부과학#§여드름]]
- **색소침착·기미** — 장벽 손상 후 염증성 색소. → [[MOC - 피부과학#§색소침착]]
- **노화** — 누적 장벽 손상 + 광노화. → [[MOC - 피부과학#§노화]]
