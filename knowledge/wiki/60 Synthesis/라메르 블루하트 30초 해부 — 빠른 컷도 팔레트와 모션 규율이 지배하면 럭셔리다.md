# 라메르 블루하트 30초 해부 — 빠른 컷도 팔레트와 모션 규율이 지배하면 럭셔리다

## 질의
라메르 Blue Heart 캠페인 30초 광고(1080p 실측 파일)는 어떤 카메라 각도·조명·빛·줌 속도·화면 전환·서사 구성으로 고급스러운 느낌을 만드는가. /watch 스킬로 19개 씬 프레임 + 8개 숏 내부 모션 프레임 + Whisper 전사 실측.

## 한 줄
컷은 빠르다(30초에 19컷, 평균 1.6초). 그런데도 느리고 고급스럽게 *느껴지는* 이유는 ① 전 숏 단일 팔레트(시안-틸 + 화이트 + 피부 골드), ② 숏 내부 카메라가 부력 속도로만 움직임, ③ 컷 전후 휘도·색·모션 벡터가 맞춰져 컷이 디졸브처럼 읽히기 때문이다. **럭셔리 = 컷 수가 아니라 "화면 간 불연속량"의 통제.**

## 실측 분해

### 1. 컷 구조 (씬체인지 검출 실측)
0:00 / 0:02 / 0:03 / 0:05 / 0:06×2 / 0:08 / 0:09 / 0:10 / 0:11 / 0:13 / 0:15 / 0:17 / 0:19 / 0:20 / 0:22 / 0:24 / 0:26 / 0:28 — 19숏, ASL 약 1.6초. 감정 숏(오프닝 응시·거북·항공 파도·마지막 유영)만 2초+로 길게 잡고 나머지는 1~1.5초. **기존 통념("샷당 3초 미만은 싸 보인다")의 반례** — 단, 아래 규율이 전제.

### 2. 카메라 각도 — 7종 로테이션
- 아이레벨 인물 클로즈업(0:00 응시) → 하이앵글(0:03 웃음) → 오버숄더 뒷모습(0:05 마스크 착용 = 시청자 초대 컷) → 수중 정면 접근(0:10, 0:26 피사체가 렌즈로 다가옴) → 수중 로우앵글 수면 올려보기(0:17 — 성당 천장 효과) → 신의 시점 항공(0:15 파도 섬) → 마크로 촉각 인서트(0:20 모래 위 맨발, 0:22 모래 쥔 손·얕은 심도).
- 원리: **친밀(마크로·클로즈업) ↔ 경외(항공·와이드)의 교차**가 스케일 대비를 만들고, 제품 없이도 "귀한 것을 보고 있다"는 감각을 만든다.

### 3. 조명·빛 — 인공광 0
- 전부 자연광. 지상: 태양을 역광/림라이트로 써서 머리카락이 금색으로 빛나고 얼굴은 바운스 필. 하이라이트를 살짝 날린 하이키 + 들뜬 블랙(lifted blacks) = 필름룩.
- 수중: ① 갓레이(0:09 물고기 떼 사이 광선) ② 수면 코스틱을 살아있는 텍스처로(0:13 거북 위 수면 전체가 은박처럼 일렁임) ③ 실루엣(0:17 역광 수면).
- 물 스파클을 백릿 스페큘러 보케로(0:05) — 보석 코드 없이 보석 질감.

### 4. 줌·무브 속도 (숏 내부 프레임 대조 실측)
- 오프닝 클로즈업: 0.0→0.8초 프레이밍 거의 동일 = 락오프/미세 드리프트. 움직이는 건 바람에 날리는 머리칼뿐.
- 거북 숏(0:13→0:14.4): 1.4초에 스케일 변화 ~10% = 유영 속도 그대로의 슬로 트래킹.
- 항공 섬(0:15→0:16.4): 드론이 섬을 잡은 채 아주 느린 오빗.
- 마지막 유영(0:26→0:27.4): 피사체가 다가오고 카메라가 물러남 — 줌이 아니라 **피사체 주도 접근**.
- 결론: 크래시 줌·휩팬·펀치인 0회. 카메라는 항상 **물의 부력 속도**로만 움직인다. 템포는 컷이 내고, 카메라는 끝까지 고요.

### 5. 화면 전환
- 100% 스트레이트 컷, 그래픽 트랜지션 0. 대신 물/뭍 교차 편집(수면 위→아래→위)이 호흡 리듬을 만들고, 인접 숏의 색·휘도가 같아서 컷이 부드럽게 읽힌다.
- 타이틀 "LA MER BLUE HEART"는 컷 없이 라이브 푸티지 위에 페이드인(0:26), 엔드카드도 실사 위 화이트 세리프 자간 넓힘 — 하드 그래픽 카드 없음.

## 기존 노트와의 긴장/보정
[[라메르가 고급스럽게 움직이는 이유 — 사람을 안 움직이기 때문이다]]는 "샷당 3초 미만·12샷 초과는 싸 보인다"고 정리했다. 블루하트 실측은 19숏/30초로 이를 넘지만 럭셔리가 유지된다. 보정된 규칙: **컷 속도는 자유변수, 불변식은 (a) 숏 내부 모션이 물성 속도 (b) 전 숏 팔레트 단일 (c) 컷 전후 휘도·모션 벡터 연속.** 셋이 지켜지면 빠른 컷도 디졸브처럼 읽힌다. 테이블탑(미라클브로스) 계열은 "빛·크림이 배우", 블루하트 계열은 "아이+바다가 배우"인 가치 필름으로 서브장르가 다르다.
