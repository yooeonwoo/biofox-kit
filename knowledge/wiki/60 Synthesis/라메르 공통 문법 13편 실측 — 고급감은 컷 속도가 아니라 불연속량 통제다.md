# 라메르 공통 문법 13편 실측 — 고급감은 컷 속도가 아니라 불연속량 통제다

## 질의
라메르 188편 레퍼런스 아카이브(`~/Downloads/LaMer_Ad_References`, 인덱스 CSV 포함)에서 장르 대표 13편을 골라 /watch 스킬 + 병렬 에이전트 12개로 프레임 단위 실측(씬 검출, 숏 내부 프레임쌍 대조로 카메라 속도 측정, Whisper 전사). 카메라 각도·조명·빛·줌·전환·서사의 공통 공식을 도출.

## 표본 (13편, 전부 프레임 실측)
Blue Heart 30s(19숏/ASL 1.6s) · Brand Film 58s(42숏/1.38s) · Crème 15s(13숏/1.16s) · Kate Hudson 49s(35숏/1.4s) · Chen Man 9.3s(6숏/1.55s) · Genaissance 71s(~40숏/1.8s) · Mystery 30s(15숏/2.0s) · How-to Crème 30s(13숏/2.3s) · Kelp Harvest 다큐 75s(28숏/2.7s) · 전지현×곤드리 46s(16숏/2.8s) · Blue Heart Ch2 다큐 123s(~37숏/3.4s) · Ana de Armas vlog 62s(ASL 3~4s) · Sienna Miller vlog 107s(사실상 원테이크) · **Heritage 185s(하드 컷 0개 — ffmpeg scdet 0.08에서도 무검출, 100% 롱 디졸브, 의미 단위 16장면, 엔딩 바다 38초 원샷)**

### Heritage가 확정한 편집 스펙트럼의 양극
ASL 1.16초(Crème 15s)부터 **컷 제로**(Heritage)까지 — 컷 속도는 완전한 자유변수임이 확정. Heritage 추가 발견: ① 무성영화 인터타이틀 문법("the HEALING / the SEA KELP / the INNOVATION / the POTENCY / the MIRACLE BROTH / the PROMISE / the BLUE HEART" — 이탤릭 소문자 the + 대문자 레터스페이싱), VO 없이 텍스트가 내레이션. ② 챕터 컬러코딩(그린→세피아→B&W→앰버→골드→화이트→틸)이 목차 역할 — Brand Film의 색온도 3막이 여기서 7막으로 확장된 동일 문법. ③ 창립 신화의 수치화("12년, 6,000번의 실험") — 노력의 정량화가 가격 정당화. ④ 제품 61% 지점 등장 + 필름 유일의 페이드 투 블랙을 리빌 직전에 배치. ⑤ 오퍼링 제스처(펼친 손바닥 위 단지) + 제품이 디졸브로 바다에 용해되며 퇴장. ⑥ 얼굴 없는 캐스팅 — 정면 얼굴 0, 손과 실루엣만.

## 한 줄
188편을 관통하는 단 하나의 물리 법칙: **광학 줌 0회, 숏 내부 카메라는 정지~부력 드리프트, 속도는 전부 편집과 피사체에 위임.** 컷은 뮤직비디오급(ASL 1.2~2.8s)으로 빨라도 되고, 대신 **화면 간 불연속량**(휘도·색·질감·모션 벡터)을 통제해 빠른 컷을 느린 꿈으로 위장한다.

## 공통 공식 (13편 교집합)

### F1. 카메라 불변식 — 전 표본 공통, 예외 0
- **광학 줌 0회.** 13편 전부. 스케일 변화는 컷 / 물리 이동(돌리·크레인·드론) / 피사체 접근으로만. 확대감이 필요하면 매크로 컷 3연타(Crème 15s 0:08)나 피사체가 렌즈로 다가오는 숏(Blue Heart 0:26).
- **숏 내부 카메라: 락오프 ~ 1-10%/s 드리프트.** 프레임쌍 실측 — Sienna 107초 동안 0%/s, How-to 0.4s↔2.6s 배경 픽셀 동일, Kate 제품숏 안개만 이동, 전지현 뷰티컷 <1%/s. 최대치도 켈프 유영 5-10%/s, 곤드리 크레인 5-8%/s.
- **움직임 에너지는 피사체가 담당**: 파도·기포·안개·머리카락·손·부유하는 용기. "카메라가 흥분하면 싸 보인다"의 정량 증명.

### F2. 편집 공식 — "빠른 컷 + 정지 카메라 + 불연속량 통제"
ASL 실측 1.16~5.2s. 럭셔리=롱테이크 통념은 전면 반박됨. 빠른 컷이 느리게 체감되는 3장치:
1. **인접 숏 톤 매칭**: 휘도·색·질감을 맞춰 컷 자체를 무봉합화 (How-to 그레이지 톤온톤, Kate의 안개→김→구름→백마→눈 "흰 텍스처 라임", Genaissance 골드→골드/네이비→네이비)
2. **숏 내부 슬로모션 물리**: 기포·파티클·액적이 슬로모로 흘러 편집 템포와 피사체 템포를 디커플링 (Crème 15s의 핵심)
3. **수퍼(자막)가 컷 3~4개를 관통**해 연속성 앵커 (Genaissance 'Sospendi il tempo'가 와이드→눈→피부 매크로까지 유지)
- 홀드는 의미 축에만: 제품 히어로·핵심 제스처·경이 숏(다시마 성당 4s, 일몰 타임랩스 6s)은 길게, 정보 숏은 1~2s.

### F3. 조명 공식 — 역광의 브랜드
- **역광/림라이트가 디폴트**: 콩트르주르 실루엣(Kelp 6숏+), 켈프 투과 골드(Crème·Kelp), 수중 갓레이(Kate 0:26, Genaissance), 얼굴 위 워터 코스틱(Mystery 0:00).
- **자연광 우선, 스튜디오도 자연광처럼**: How-to의 무영 세트조차 "공기 같은 빛"으로 위장. vlog는 창광 하이키.
- **물의 광학 현상 = 조명 장치 목록**: 코스틱 / 갓레이 / 스페큘러 글린트 / 워터 셔머 / 안개 롤오프 / 블로운 화이트아웃 플래시(Kate 0:27, Mystery 0:17 — 두 색 세계의 접합부).
- **듀이 스킨 스페큘러 = 효능의 조명 증명**: 광대·이마 물광 하이라이트로 "보습 결과"를 말 대신 빛으로 진술 (How-to, Ana, Sienna).

### F4. 팔레트 공식 — 단일 지배색 + 보색 1
- 전 편이 **지배 1색 + 액센트 1색**: 네이비×골드(Crème 15s·Genaissance·Mystery), 딥블루×오렌지(BH Ch2), 그린×러스트(Sienna), 틸×마젠타(Chen Man·Brand Film 오프닝), 그레이지 모노(How-to).
- **골드 = Miracle Broth의 시각 상표**: Brand Film은 40초부터 화면 전체가 황금으로 물들고(색온도 3막), Mystery·Genaissance·Crème 15s 모두 발효 구간에서 골드가 최고 채도 점유.
- **패키지 색 = 세트 팔레트** (How-to): 어느 프레임을 캡처해도 캠페인 스틸.
- 채도 절제가 기본, **팔레트 파괴는 단발 1회만** 허용 — 계산된 충격 (Genaissance 마젠타 해조 블룸).

### F5. 타이포 불변식 — 전 표본 공통
Didot/디돈계 세리프 · 화이트 · 넓은 자간 · 중앙 또는 좌하 · **키워드만 이탤릭** ('NEW', 'SECRET', 'Sospendi') · 그래픽 카드 대신 실사 위 페이드인. 이 타이포 하나가 UGC vlog조차 럭셔리 액자에 넣는다(Ana 오프닝/엔드카드 브래킷). 유일한 예외 Kelp 다큐는 텍스트 0 — 그것도 자신감의 표현.

### F6. 제품 스테이징 스펙트럼 — "선반 위 상품" 금지
| 전략 | 사례 | 등장 시점 |
|---|---|---|
| 완전 부재 | Blue Heart 계열, Chen Man, Kelp | -1 (팔지 않는 여유) |
| 바다의 유물 | Crème 15s 심해 부유, Mystery 물결 테이블탑, Brand Film 파도 직격 | 0:02~ |
| 안개/느린 리빌 | Kate (러닝타임 78% 지점, 안개가 걷히며) | 후반 몰빵 |
| 리추얼 도구 | How-to, Genaissance (조기 등장+반복 = 의식) | 0초~ |
| 친구의 비밀 | Ana·Sienna 인핸드 증언 | ~18s |

공통 원리: 제품은 **채굴된 보물 / 성물 / 리추얼 도구 / 친구의 귀띔** 중 하나로만 존재. 등장 시점은 자유변수, 스테이징 격이 불변식.

### F7. 서사 아키텍처 — 단일 신화, 4장르 포트폴리오
모든 편이 **Miracle Broth 연금술 신화**(바다 → 켈프 → 발효 → 생명력 → 피부)의 다른 절단면:
1. **신화·가치 필름** (Blue Heart, Chen Man): 제품 0, "바다=브랜드" 등식 자체를 적립
2. **프로비넌스 다큐** (Kelp, Heritage, BH Ch2): 원산지·수공·역사로 가격 정당화. 러프 화질이 진정성 증거
3. **시네마틱 캠페인** (Brand Film, Crème 15s, Genaissance, Kate, 전지현, Mystery): 바다→성분→피부 아크, 시 VO 또는 무성 수퍼
4. **셀럽 인티머시** (Ana, Sienna GRWM) + **리추얼 하우투**: UGC 문법을 세리프+셀럽+하이키 미장센으로 액자화. 하드셀이 "친구 추천"으로 세탁됨

VO 스펙트럼(속삭임 시 / 다큐 해설 / 실존 육성 / 무성 / 수다)은 다양하지만 공통 규율: **판매 어휘를 리추얼·시·과학·우정의 언어로 번역** ("warming ritual", "Miracle Broth", "lucky me").

### F8. 룰브레이크 성립 조건 (럭셔리가 규칙을 깨고도 사는 법)
- 빠른 컷 OK ← 카메라 정지 + 톤 매칭이 지불
- 하드셀 클레임 OK ← 세리프 시적 조판(Crème 15s 'VISIBLY REVERSE AGE') 또는 셀럽 1인칭(Ana)이 지불
- 러프 화질·안전조끼·플라스틱 빈 OK ← 다큐 진정성으로 치환(Kelp)
- 조기 제품 노출 OK ← 리추얼 반복 프레이밍(Genaissance)
- 팔레트/카메라 규범 위반 OK ← 클라이맥스 1숏에만(Chen Man 더치앵글 POV)
→ 메타 규칙: **규범 위반은 반드시 다른 축의 잉여 규율이 담보할 때만 1개 축에서 허용.**
