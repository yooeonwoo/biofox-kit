# 바이오폭스 매거진 GEO·AEO 전략 — 탈잉 강의 분석과 적용 지점

> 질의: biofox-main 매거진 페이지에 GEO/AEO 최적화 글을 써서 AI 검색지수(AI citation)를 늘리려면?
> 입력 자료: 탈잉 GEO·AEO·SEO 올인원 가이드 PPT(207p), SEO/AEO/GEO 용어집, 데니스 SEO 실습 프롬프트 킷 8종.
> 강의 원자노트는 이미 `50 Wiki/마케팅/`에 ingest 완료 상태였음 — 이 노트는 그 지식을 바이오폭스 매거진에 매핑한 종합.

## 1. 강의 핵심 골자 (원자노트 링크)

- 목표 지표는 **AI Citation** — AI 답변에 출처로 인용되는 횟수. GEO 시대 초기 선점 효과가 가장 큰 시기는 지금이다 (사례: GEO 트래픽 전환율이 SEO 대비 6배)
- GEO는 별도 기법이 아니라 정석 SEO 위에 얹는다. GEO는 SEO의 확장이지 대체가 아니다 · AI 시대일수록 SEO 기본기가 검색 노출의 가장 빠른 길이다
- AI가 인용하는 구조 3기준: AEO가 좋아하는 콘텐츠 구조는 Q&A 정의화 구조화 3가지다 (질문에 대한 명확한 답 / 정의화 / 비교·기준의 구조화 — 표, 리스트, 단계형)
- 제작 프로세스: SEO 글쓰기 5단계 프로세스는 키워드 선택에서 시작해 SEO 설정으로 끝난다 (키워드 → 개요 → 본문 → 자료 → SEO 설정, 1글 1메인키워드)
- 키워드 전략: 롱테일 키워드는 전환율이 높고 경쟁이 낮아서 초기 SEO에 유리하다 + 검색량 없어도 유입을 만드는 2가지 백도어 전략 (Pain Point 공략 / 인기 키워드 우회)
- 차별화: E-E-A-T와 휴먼터치가 AI 시대 콘텐츠의 차별화 핵심이다 — B2B는 세일즈 미팅 기록·회의록, B2C는 FAQ·실고객 후기를 AI에 입력해 경험 요소를 만든다
- 측정: SEO 모니터링은 오가닉 트래픽 키워드 순위 AI Referral 3가지만 보면 된다 · 개선: 콘텐츠 순위별 개선 전략은 1~3위 4~10위 11~20위로 나뉜다

## 2. 데니스 프롬프트 킷 8종 = 5단계 프로세스의 실행 파이프라인

1. 검색의도 분석 + H1~H3 개요 → 2. H2/H3를 GEO 기준 진단(유지/수정/삭제, 사용자 확인) → 3. 목적·톤·CTA 확인 후 본문 초안(웹검색 근거+출처) → 4. 초안 검수(자연스러움·전달력·충분성·독창성·E-E-A-T) → 5. AEO 구조 업그레이드(결론 우선·표·단계형) + 이미지 가이드(alt text) → 6. 타이틀·메타 디스크립션 5종 → 7. URL 슬러그 3종 → 8. 롱테일 키워드 50개.
프롬프트 2·3·4가 사용자 확인 게이트를 내장 — 자동화 시에도 이 게이트는 유저 결정으로 남긴다.

## 3. biofox-main 매거진 현재 상태 (2026-08-19 실측)

- `src/app/(shop)/magazine/` 목록 + `[slug]` 상세, `src/app/admin/magazine/` CMS 존재.
- 기술 SEO 기반 이미 있음: `generateMetadata`(목록·상세), canonical, openGraph, JSON-LD, sitemap.ts에 /magazine 등재, robots.ts.
- 즉 **기술 SEO는 소폭 보강만 필요, 병목은 콘텐츠**. 상세 페이지 JSON-LD를 Article 스키마(author·datePublished)로 확장하고 FAQPage 스키마 추가 여지 확인 필요.

## 4. 바이오폭스 적용 지점

- 키워드 후보 축 3개: ① 성분·기전 정보형(EGF/FGF/성장인자 — [[MOC - 피부과학]] 원자노트가 근거 소스), ② 시술 후 케어 Pain Point 롱테일(백도어 전략 1), ③ 인기 키워드 우회(백도어 전략 2).
- E-E-A-T 원천은 이미 위키에 있음: 임상 사진([[임상 사진은 에스테틱 마케팅의 모든 콘텐츠 소재의 원천이다]]), 상담·세일즈 기록, FAQ.
- 컴플라이언스 게이트 선행 필수: 레이저 광고는 기기 효과가 아니라 후처치 필요를 말해도 심의 대상이다 · [[BIOFOX 콘텐츠는 브랜드·전문의·경쟁시술 실명과 성분 공격을 피하고 결론 축으로 수렴한다]] — 의료기기·화장품 표현 심의를 프롬프트 4(검수) 단계에 게이트로 추가해야 한다 (강의 킷에는 없는 바이오폭스 고유 단계).
- 발행 리듬: 주 2~3회, 최소 20~30개 누적까지는 클릭이 아니라 노출수(Impressions) 추세만 본다.
