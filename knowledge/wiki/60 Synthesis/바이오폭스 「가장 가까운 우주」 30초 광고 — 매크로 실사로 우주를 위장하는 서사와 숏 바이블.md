# 바이오폭스 「가장 가까운 우주」 30초 광고 — 매크로 실사로 우주를 위장하는 서사와 숏 바이블

> **⚠️ 2026-08-20 대체됨**: 사용자 피드백("바이오·유전자재조합·EGF 느낌 부재, 시네마틱 부족") → 서사를 **「시간을 다시 쓰다」 90초 35컷**으로 전면 교체. 하루가 거꾸로 흐르는 색온도 아크(황혼→랩→역행→새벽), 서열 교체=유전자 재조합 시각 번역, 배우급 모델 뷰티 모드. 프로덕션 바이블: `~/orca/projects/yoochatbot/deliverables/biofox-rewrite-time/bible.html` (아티팩트 발행). 이 노트의 자산 중 S2B(방울 스타버스트)·S3v2(액적)는 새 필름 2막에 재활용됨.

## 질의
라메르 13편 실측 공식만으로 바이오폭스 광고 서사를 제로베이스 설계(기존 「역행」 대체 아님 — 병행 자산). 요구: 바이오·유전자 재조합·EGF/FGF 강조 + 우주 은유. Seedance 2.5 + Higgsfield 제작 전제.

## 한 줄
라메르가 "바다의 에너지를 피부로"라면 바이오폭스는 **"몸이 원래 가진 힘을 피부로"** — 우주는 CG가 아니라 **우주처럼 읽히는 테이블탑 매크로 실사**(트리 오브 라이프 수조 잉크 기법)로만 위장하고, **별자리 재배열 = 유전자 재조합**이라는 시각 등식으로 DNA 나선 CG 금지 원칙을 지키면서 기술을 전면에 세운다.

## 서사 (30초 5비트)
1. **별 필드** (0–5s) — 수조 부유 입자 역광 = 심우주로 위장. "우주는, 멀리 있지 않습니다."
2. **성운·별의 탄생** (5–12s) — 라벤더 잉크 확산(정방향 생성 → 후반 역재생 팔린드롬) → 방울 응축 + 스타버스트. "피부 아래 — 매일, 별이 태어나는 곳."
3. **별자리 재조합** (12–19s) — 검은 유리 위 세럼 방울 별자리, 글린트가 신호처럼 주행, 방울 2개 합체 + 연결선 재배열. 자막 "유전자 재조합 EGF·FGF — 몸과 동일한 구조."
4. **리빌** (19–26s) — 전 편 유일의 큰 무브: 방울 내부 은하 → 풀백 → 은하가 노즐 끝 한 방울이었음 → 워터 테이블탑 히어로(수면에 별 반사). 착지 순간 음악 풀 드롭아웃.
5. **피부의 별** (26–30s) — 프로필 림라이트, 피부 듀이 하이라이트 = 별의 라임. 타이포 "가장 가까운 우주 / BIOFOX."

핵심 장치: 구조 트릭(25초까지 우주 다큐인 척 → 리빌로 "우주=몸속" 증명) / 색채 라임(별빛 라벤더 = 세럼 라벤더, 라메르의 노을금=브로스금 등가) / 팔레트 #0A0E1A + #B9A7E6 단일 규율.

## 제작 결정
- **원패스 금지, 클립 조립**: Seedance 멀티샷은 ASL≥6s라 라메르 리듬(1.2~2.8s) 재현 불가 + 실패 격리 + 후반 열화 회피. 연속 변형(성운·풀백)만 10~15s 원샷.
- **잉크 역재생은 생성 아닌 편집**: 정방향 확산만 뽑고 후반에서 거꾸로(실촬영과 동일 기법, 100% 확정적).
- **오디오 클립별 생성 금지** — 음악 1트랙 통으로(컷 관통 접착제).
- 스틸 먼저 락 → first-frame 레퍼런스로 영상 생성. 마스터 16:9 생성 → 2.39:1 크롭.

## 시작 프레임 7컷 실측 (gpt-image-2, 2026-08-20)
- 컴파일 규칙: 전부 긍정형(네거티브 0)·렌더 텍스트 0·"실사 테이블탑 수조 촬영—심우주처럼 읽히는" 앵커를 첫 문장에 — CG 슬롭 차단의 핵심.
- 판정: S2A 성운·S2B 방울점화·S4A 방울내부·S4B 워터히어로·S5 프로필 = 합격. S1(입자가 직물 글리터로 읽힐 위험)·S3(방울이 금속 구슬로 읽힐 위험) = 사용 가능하나 리테이크 후보.
