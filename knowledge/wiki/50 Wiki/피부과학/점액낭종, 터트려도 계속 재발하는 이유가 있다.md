# 점액낭종, 터트려도 계속 재발하는 이유가 있다

## Main Idea
점액낭종은 터트리면 끈적한 투명한 물질이 나오지만 시간이 지나면 같은 자리에 재발한다. 입안의 경우 침샘관 손상으로 인해 침이 고여서 형성되고, 손가락의 경우 관절낭이 튀어나와 발생한다.

## Context
단순히 터트리는 것만으로는 근본 원인이 해결되지 않아 재발이 반복되는 구조적 문제를 이해해야 한다.
