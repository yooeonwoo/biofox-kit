# 피부 장벽 기능 저하가 지루두피염의 핵심 원인이다

## Main Idea
지루두피염은 단순한 두피 문제가 아니라 피부 장벽 기능이 떨어져 있거나 회복력이 저하된 상태에서 발생한다. 특히 외부 환경 변화(추위, 건조함)에 대한 피부의 방어력이 약해져서 각질 과다 생성으로 이어진다.

## Context
기존의 단순한 비듬 치료법으로는 근본적 해결이 어려운 이유를 설명해준다.
